Xử lý rò rỉ bộ nhớ (Memory Leak) khi duyệt và giải phóng con trỏ cây B-Tree bậc 5?

Em gặp trường hợp khi chạy hàm xóa cây clearTree(BTreeNode* root) qua valgrind thì bị báo mất 128 bytes trên heap do các con trỏ con chưa được giải phóng đệ quy đúng thứ tự mảng keys. Đoạn code C++ của em như sau:

btree_clear.cpp
C++17 • Valgrind Heap Leak 
void clearTree(BTreeNode* root) {
    if (root == nullptr) return;
    for (int i = 0; i <= root->numKeys; i++) {
        clearTree(root->children[i]); // Bị bỏ sót nút lá khi leaf == true
    }
    delete[] root->keys;
    delete[] root->children;
    delete root;
}

Chào em Nam. Trong hàm đệ quy của em, khi root->isLeaf == true thì mảng children không chứa con trỏ hợp lệ, dẫn đến duyệt qua mảng rác (garbage pointer) trước khi xóa. Em chỉ cần bọc điều kiện kiểm tra lá trước vòng lặp duyệt con:

if (!root->isLeaf) { for (int i = 0; i <= root->numKeys; i++) clearTree(root->children[i]); }
